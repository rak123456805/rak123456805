## 🌟 Featured Projects

### 🥇 ReelRag — Video Content Intelligence Platform
> **Multi-Platform Video RAG Engine** | `Next.js 14` • `FastAPI` • `LangGraph` • `Weaviate Cloud` • `OpenAI/Gemini`
- **Cross-Platform Pipeline:** Orchestrates metadata and transcript extraction across YouTube, Instagram, X (Twitter), and TikTok using fallback mechanisms and `yt-dlp` to navigate strict API rate limits and structural blocks.
- **Stateful Streaming & Citations:** Engineered asynchronous Python generators to deliver real-time Server-Sent Events (SSE) chat streaming, synchronized perfectly with stateful agent graphs and exact timestamp source citations.
- **Granular Temporal Chunking:** Implemented advanced custom text-splitting strategies mapped to dedicated vector database schemas in Weaviate, returning contextual source segments down to the precise millisecond.
- **High-Availability Failover:** Built an automatic infrastructure failover routing mechanism. If the primary OpenAI engine hits rate limits or experiences downtime, the LangGraph layer seamlessly hot-swaps to Google Gemini natively without breaking the session state.
- [**🚀 Live Demo →**](https://video-ai-02.vercel.app/) | [**💻 View Repository →**](https://github.com/rak123456805/videoAi_02.git)
